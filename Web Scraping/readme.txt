BeautifulSoup adalah tool yang memungkinkan untuk mengambil kode pada sebuah situs web.
A.	Environment Setup
1.	Ketik “python -m pip install pipenv” di terminal
2.	Ketik “python -m pipenv shell”. Ini menciptakan lingkungan virtual dan mengaktifkannya secara bersamaan.
3.	Ketik “python -m pip install requests”, ini adalah python library yang memungkinkan anda mengambil halaman web
4.  Ketik "python -m pip install beautifulsoup4", ini adalah pyhton library untuk menginstall beautifulsoup
